## 关键问题
1. 哪些中文属于真实 UI 文案，而不是注释或文档？
2. 是否存在服务端返回给 UI 的中文错误文案需要同步改为英文？

## 已做决策
| Decision | Rationale |
|----------|-----------|
| 只修改用户可见文案，不处理注释/文档中的中文 | 用户要求是“界面上的中文” |
| 同时覆盖 UI 组件与 UI 会展示的客户端错误消息 | 避免界面仍出现中文反馈 |
| 保留 `日本語` 等非中文语言名称不变 | 用户只要求把中文改成英文 |
