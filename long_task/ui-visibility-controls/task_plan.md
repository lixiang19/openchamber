## 关键问题
1. 会话列表顶部“每个按钮都能设置”是否覆盖 `worktree`、`multi-run`、`project notes`、`search`、`display mode` 全部按钮？
2. 右侧标签全部关闭时，右侧栏是否保留空态占位，还是自动折叠？
3. 这些显示控制是否仅影响可视 UI，不影响快捷键或命令面板入口？

## 已做决策
| Decision | Rationale |
|----------|-----------|
| 使用独立长任务目录记录本轮 UI 设置改造 | 这是客户端长期改造的第二个子任务，需要独立追踪 |
| 顶部按钮状态采用对象形式写入 `useUIStore` 与 settings | 五个按钮属于同一组偏好，聚合后更容易渲染与同步 |
| 右侧标签可见性同样采用对象形式 | Git/Files/Todo 三项天然属于一组，后续扩展也更简单 |
| 当当前右侧标签被隐藏时，自动切到下一个可见标签 | 避免界面停留在一个被隐藏的 tab 上 |

## 注意事项

- 尽量复用现有 `OpenAuroraVisualSettings` 和 `updateDesktopSettings` 模式
