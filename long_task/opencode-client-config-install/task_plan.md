## 关键问题
1. 仓库内预置模板目录应放在哪个位置，便于后续持续扩展 agent/skill/config 内容？
2. 覆盖安装是否只面向桌面端，还是也要兼容 Web/VS Code 运行时？
3. 上传文件夹后对目标目录采用“整体覆盖”还是“仅覆盖同名文件并保留其他文件”？

## 已做决策
| Decision | Rationale |
|----------|-----------|
| 使用长任务文件记录本次改造 | 这是用户明确提出的长期改造起点，后续会持续迭代 |
| 预置模板放在 `packages/web/server/opencode-template/` | 模板需要随 Web/Desktop 运行时一起分发，不能依赖仓库根目录在生产环境存在 |
| 新增独立 Settings 单页而不是塞进现有 OpenAuroraPage | 该功能是明确的安装器入口，单独页面更直达，也更便于后续扩展更多平台定制工具 |
| 上传文件夹同时支持桌面原生目录选择与浏览器文件夹上传 | 桌面端可直接复制本地目录，Web/其他运行时则可回退为文件夹上传，避免功能只在一种 runtime 可用 |
