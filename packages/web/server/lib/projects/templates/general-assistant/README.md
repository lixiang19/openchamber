# {{PROJECT_NAME}}

你的专属 AI 助手项目，由 ridge 创建。

## 关于这个助手

这个项目的核心是 **{{AI_NAME}}**，一个为你 {{USER_NAME}} 服务的通用型 AI 助手。

## 快速开始

1. **完善用户档案**：编辑 `USER.md`，填写你的偏好、技术背景和沟通风格
2. **调整性格设置**：编辑 `SOUL.md`，自定义助手的性格和价值观
3. **配置技能**：编辑 `AGENTS.md`，选择你想要启用的工具和技能
4. **记录重要信息**：编辑 `MEMORY.md`，保存你希望助手长期记住的事实

## 文件说明

| 文件 | 用途 |
|------|------|
| `SOUL.md` | AI 的性格、核心价值观和长期指令（最重要） |
| `IDENTITY.md` | AI 的身份和能力说明 |
| `USER.md` | 你的个人档案和偏好 |
| `MEMORY.md` | 持久记忆存储 |
| `AGENTS.md` | 工具与技能配置 |
| `ridge.md` | ridge 平台使用说明 |

## 使用建议

- 定期更新 `MEMORY.md`，添加新的重要信息
- 当 AI 的行为不符合预期时，检查并调整 `SOUL.md`
- 随着使用深入，不断完善 `USER.md` 中的个人档案
