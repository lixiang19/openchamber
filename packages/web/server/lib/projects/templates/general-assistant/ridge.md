# Ridge 平台使用指南

## 这是什么

这是一个 **ridge 受管项目**，专为 AI 助手设计。

与传统的代码项目不同，这个项目的核心是定义 AI 助手的性格、能力和与你的协作方式。通过编辑项目中的 Markdown 文件，你可以完全定制 {{AI_NAME}} 的行为。

## 核心文件说明

| 文件 | 重要性 | 说明 |
|------|--------|------|
| **SOUL.md** | ⭐⭐⭐ 最重要 | 定义 {{AI_NAME}} 的性格、价值观和长期指令 |
| **IDENTITY.md** | ⭐⭐⭐ 重要 | {{AI_NAME}} 的身份和能力说明 |
| **USER.md** | ⭐⭐⭐ 重要 | 你的个人档案，帮助 {{AI_NAME}} 了解你 |
| **MEMORY.md** | ⭐⭐ 重要 | 持久记忆存储，记录重要事实和决策 |
| **AGENTS.md** | ⭐⭐ 中等 | 技能和工具配置 |
| **README.md** | ⭐ 参考 | 项目总览和快速开始 |

## 快速上手

### 第 1 步：完善用户档案

编辑 `USER.md`，填写：
- 你的称呼和基本信息
- 沟通偏好（语言、风格、长度）
- 技术背景
- 工作模式（时区、工作时段）

### 第 2 步：设定助手性格

编辑 `SOUL.md`，调整：
- 性格特点（友好/专业/严谨/幽默等）
- 核心价值观（隐私、安全、准确性等）
- 长期指令（回复格式、沟通方式等）

### 第 3 步：开始对话

在 ridge 中与 {{AI_NAME}} 对话，体验个性化服务。

## 使用技巧

### 如何让 {{AI_NAME}} 记住重要信息

1. 直接在对话中说"记住这个：..."
2. 手动编辑 `MEMORY.md` 文件
3. 定期回顾和整理记忆文件

### 如何调整 {{AI_NAME}} 的行为

如果 {{AI_NAME}} 的回复不符合预期：
1. 检查 `SOUL.md` 中的性格设置
2. 在 `USER.md` 中更新你的偏好
3. 在对话中直接给出反馈

### 最佳实践

- **保持 SOUL.md 精简**: 性格定义在 200-500 字最有效
- **定期更新 MEMORY.md**: 每月回顾一次，清理过期信息
- **使用版本控制**: 这是一个 Git 项目，提交重要的配置变更
- **迭代优化**: 根据实际使用体验调整配置

## 高级用法

### 多角色切换

你可以创建多个项目，每个项目代表一个专门的助手：
- `my-writing-partner/` - 写作助手
- `my-code-reviewer/` - 代码审查助手
- `my-research-assistant/` - 研究助手

### 共享配置

你可以将 `SOUL.md` 和 `AGENTS.md` 分享给他人，作为模板基础。

### 自动化工作流

在 `AGENTS.md` 中定义定期任务和自动化流程。

## 故障排除

### {{AI_NAME}} 似乎没有读取配置文件

- 确保文件保存后已经同步
- 检查文件格式是否为有效的 Markdown
- 尝试重启对话会话

### 回复不符合预期

- 检查 `SOUL.md` 中的指令是否明确具体
- 避免冲突的指令（如同时要求"简洁"和"详细解释"）
- 在 `USER.md` 中补充更多上下文

### 记忆没有持久化

- 重要信息需要显式记录在 `MEMORY.md`
- 定期备份项目目录
