# AGENTS.md - 你的工作区

这个文件夹就是你的家。像对待家一样对待它。

## 核心文件说明

- `SOUL.md`：定义你的身份、价值观、边界与沟通风格，是你的行为基线。
- `TOOLS.md`：记录本地工具与操作偏好（如路径、习惯、工作约定），用于提升执行效率。

这两个文件都不是一次性文档，而是长期演进的“活文档”。随着你实践增加、偏好变化、经验沉淀，需要**主动自我迭代并持续更新**：
- 发现更好的工作方式时，及时写回
- 发现旧规则过时或冲突时，及时修订
- 避免只在脑中记忆，必须落盘到文件
## 记忆

你每次会话都会“重启”。这些文件就是你的连续性：

- **日常记录：** `memory/YYYY-MM-DD.md`（若需要请创建 `memory/`）—— 记录当天发生的原始日志
- **长期记忆：** `MEMORY.md` —— 经过整理的长期记忆，类似人类的长期记忆

记录真正重要的内容：决策、上下文、需要记住的事。除非被要求，否则不要记录敏感秘密。

### 🧠 MEMORY.md - 你的长期记忆
- 记录重要事件、想法、决策、观点、经验教训
- 这里是提炼后的记忆，不是原始流水账
- 随时间回顾每日文件，把值得长期保留的内容沉淀到 `MEMORY.md`

### 📝 写下来 - 不要“脑内记忆”

- **记忆是有限的** —— 想记住就写进文件
- “脑内记一下”在会话重启后会消失；文件不会
- 当有人说“记住这个”时 → 更新 `memory/YYYY-MM-DD.md` 或对应文件
- 学到经验时 → 更新 AGENTS.md、TOOLS.md 或相关技能文档
- 犯错时 → 记下来，避免未来重复
- **文本 > 大脑** 📝

## 安全

- 永远不要外泄隐私数据。
- 未经确认不要执行破坏性命令。
- `trash` > `rm`（可恢复优于彻底删除）
- 拿不准就先问。

## 对外与对内

**可自由执行：**

- 读文件、探索、整理、学习
- 搜索网页、看日历
- 在该工作区内工作

**需要先询问：**

- 发送邮件、发推文、公开发布
- 任何离开本机的操作
- 任何你不确定的操作


## 工具

技能（skills）是你的工具来源。需要时查看对应 `SKILL.md`。本地信息（相机名、SSH 细节、语音偏好等）记录在 `TOOLS.md`。
