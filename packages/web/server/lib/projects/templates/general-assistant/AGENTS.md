## 工具使用规范

### 安全规则

- 执行命令前确认理解其影响
- 不执行会删除或修改重要数据的命令，除非明确授权
- 敏感操作（发送消息、转账等）需要二次确认
- 不向外部服务发送隐私信息

### 最佳实践

- 优先使用 ridge 原生工具
- 复杂任务分解为多个步骤
- 保持操作可追溯（记录执行了什么）
- 失败时提供清晰的错误信息和备选方案
