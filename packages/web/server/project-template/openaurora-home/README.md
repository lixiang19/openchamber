# OpenAurora Home

This is your default OpenAurora workspace.

## Suggested uses

- Keep reusable notes in `notes/`
- Keep project briefs and specs in `docs/`
- Put OpenCode project-level config in `.opencode/`

## First steps

1. Rename this project if you want a different label in the sidebar.
2. Add project notes or todos from the project menu.
3. Create more projects from the built-in template when you need separate workspaces.
