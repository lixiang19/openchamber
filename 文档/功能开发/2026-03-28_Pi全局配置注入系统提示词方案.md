# Pi 全局配置注入系统提示词方案（MVP 修订版）

- 状态：已修订 / 待实施
- 日期：2026-03-28
- Owner：ridge
- 审查：ChatGPT（via Oracle）
- 目标版本/里程碑：Pi 配置系统 MVP

## 1. 背景与问题

- 背景：用户希望类似 OpenClaw 的方式，通过配置文件指定多个文件（AGENTS.md 等）自动注入 Pi 的系统提示词，实现可配置的 AI 助手人格和工作流
- 现象/痛点：当前 Ridge 的 Pi 集成仅支持固定的系统提示词，没有灵活的文件加载机制。项目模板虽然生成了 SOUL.md、AGENTS.md 等文件，但这些文件内容没有真正进入 Pi 的系统提示词
- 成功定义：在全局 JSON 配置中添加 `instructions` 字段，指定相对文件路径列表，这些文件内容自动读取并通过 Pi 原生机制注入系统提示词

## 2. 目标与非目标

- 目标（MVP 收敛）：
  - 在 Pi 配置中添加 `instructions` 字段，支持**相对文件路径列表**（首期**不支持 glob**）
  - 通过 Pi 原生 `DefaultResourceLoader.appendSystemPromptOverride` 机制注入（callback + reload）
  - 与项目模板联动：模板生成文件时**完成变量替换**，运行时只读取现成文件
  - 加强安全沙箱：路径归一化、防越界、防 symlink 逃逸
- 非目标（首期不做）：
  - 不支持 glob 模式（如 `packages/*/AGENTS.md`）
  - 不支持运行时变量替换（只在项目创建时渲染）
  - 不支持远程 URL 加载
  - 不替代 Pi 的 SKILL.md 技能系统
  - 不做实时文件监听（会话启动时读取一次）
  - 不做 UI 调试预览（M4 剥离到后续优化）

## 3. 现状探索（Explorer）

### Pi SDK 能力（修订）
- Pi 推荐使用 `DefaultResourceLoader` 介入资源加载，而非直接设置 `initialState.systemPrompt`
- `DefaultResourceLoader` 支持：
  - `systemPromptOverride`：完全替换系统提示词
  - `appendSystemPromptOverride`：在默认 prompt 后追加内容
  - `agentsFilesOverride`：注入虚拟 AGENTS.md 作为上下文文件
- Pi 原生已支持从全局目录、当前目录、父目录自动发现 `AGENTS.md` / `CLAUDE.md`
- 直接覆盖 `initialState.systemPrompt` 可能导致：丢失默认工具说明、技能说明、重复注入问题

### Ridge 现有集成
- Ridge 使用 `@mariozechner/pi-coding-agent` npm 包（版本 0.62.0）
- 创建会话：`createAgentSession()` 在 `packages/ui/src/stores/` 相关文件中使用
- 当前系统提示词：固定字符串，无动态加载机制
- Pi Session 类型定义：`packages/ui/src/stores/types/sessionTypes.ts`

### 项目模板现状
- `packages/web/server/lib/projects/templates/general-assistant/` 已创建
- 包含：SOUL.md、AGENTS.md、IDENTITY.md、USER.md、MEMORY.md
- 模板元数据：`template.json` 定义了 `renderFiles` 列表
- 模板变量：`PROJECT_NAME`、`AI_NAME`、`USER_NAME`、`DATE`

## 4. 资料与依据（Librarian）

- 关键结论（修订）：
  - **Pi 原生资源装载机制优于直接设置 systemPrompt**：MVP 采用 `DefaultResourceLoader.appendSystemPromptOverride` 追加内容，保留 Pi 默认的工具说明、技能说明、上下文文件发现逻辑
  - **避免与 Pi 原生机制重复**：Pi 已自动发现 `AGENTS.md`，Ridge 不应再手动拼装或覆盖；`agentsFilesOverride` 仅作为 Post-MVP 备选方向评估
  - **变量替换应在项目创建时完成**：`{{PROJECT_NAME}}` 等变量在项目创建时渲染进文件，运行时只读取现成文件，避免耦合
  - **安全沙箱必须严格**：仅靠"相对路径"不够，需防范 `../`、绝对路径、符号链接逃逸

## 5. 方案概览（主方案 - MVP 简化版）

### 5.1 方案摘要

- 一句话：在 Pi 配置中添加 `instructions` 字段，指定**相对文件路径数组**（无 glob），通过 `DefaultResourceLoader.appendSystemPromptOverride` 注入，变量替换只在**项目创建时**完成
- 取舍：首期放弃 glob 和运行时变量替换，换取与 Pi SDK 的兼容性和安全性
- 影响面：Pi 配置类型、Agent 初始化流程（使用 DefaultResourceLoader）、项目创建流程（模板渲染）

### 5.2 风险与回滚

- 风险：
  - **与 Pi 原生 AGENTS.md 发现机制冲突**：缓解措施 - 使用 `appendSystemPromptOverride` 追加而非直接覆盖，保留原生逻辑
  - **文件读取安全边界**：缓解措施 - 严格的沙箱规则（见 6.3 安全设计）
  - **内容过大导致超限**：缓解措施 - 限制单文件和总字节数，超限硬失败报错
- 回滚：
  - 功能开关：`instructions.enabled` 可快速关闭
  - 回退到当前固定系统提示词行为

interface InstructionsConfig {
  /**
   * 是否启用指令注入
   * @default false  // MVP 期默认关闭，稳定后改 true

### 6.3 安全设计（严格沙箱）

文件读取必须满足以下所有条件，否则**硬失败（hard error）**：

1. **路径必须是 regular file**：使用 `lstat` 检查，拒绝目录、socket、FIFO 等
2. **扩展名白名单**：只允许 `.md`、`.txt`、`.mdx` 文件
3. **禁止绝对路径**：路径不能是 `/` 或 `C:\` 开头
4. **禁止上级目录**：路径不能包含 `..` 或 `~`
5. **路径归一化与沙箱检查**：使用 `realpath + path.relative` 确保文件在项目根下
6. **禁止符号链接逃逸**：`realpath` 后必须仍在项目根下
7. **大小限制**：单文件超 `maxFileBytes` 时报错，总大小超 `maxTotalBytes` 时停止并报错
8. **UTF-8 验证**：文件内容必须能正确解码为 UTF-8

**错误分类处理**：

| 错误类型 | 说明 | 处理方式 |
|----------|------|----------|
| `ENOENT` | 文件不存在 | 按 `onMissingFile` 配置（ignore/warn/error） |
| `PATH_TRAVERSAL` | 包含 `..` 或绝对路径 | **硬失败** |
| `SYMLINK_ESCAPE` | 符号链接指向项目外 | **硬失败** |
| `NOT_REGULAR_FILE` | 不是普通文件（目录/socket等） | **硬失败** |
| `INVALID_EXTENSION` | 扩展名不在白名单 | **硬失败** |
| `FILE_TOO_LARGE` | 单文件超 `maxFileBytes` | **硬失败** |
| `TOTAL_TOO_LARGE` | 总内容超 `maxTotalBytes` | **硬失败** |
| `NOT_UTF8` | 无法解码为 UTF-8 | **硬失败** |

```typescript
// 安全文件读取实现（修正版）
enum SecurityError {
  PATH_TRAVERSAL = "PATH_TRAVERSAL",
  SYMLINK_ESCAPE = "SYMLINK_ESCAPE",
  NOT_REGULAR_FILE = "NOT_REGULAR_FILE",
  INVALID_EXTENSION = "INVALID_EXTENSION",
  FILE_TOO_LARGE = "FILE_TOO_LARGE",
  TOTAL_TOO_LARGE = "TOTAL_TOO_LARGE",
  NOT_UTF8 = "NOT_UTF8",
}

const ALLOWED_EXTENSIONS = new Set([".md", ".txt", ".mdx"]);

function validateAndReadFile(
  projectRoot: string,
  relativePath: string,
  maxFileBytes: number
): { content: string; bytes: number } {
  // 1. 扩展名检查
  const ext = path.extname(relativePath).toLowerCase();
  if (!ALLOWED_EXTENSIONS.has(ext)) {
    throw new Error(`${SecurityError.INVALID_EXTENSION}: ${relativePath}`);
  }
  
  // 2. 路径格式检查
  if (path.isAbsolute(relativePath)) {
    throw new Error(`${SecurityError.PATH_TRAVERSAL}: Absolute path not allowed: ${relativePath}`);
  }
  if (relativePath.includes("..") || relativePath.startsWith("~")) {
    throw new Error(`${SecurityError.PATH_TRAVERSAL}: Path traversal detected: ${relativePath}`);
  }
  
  // 3. realpath 归一化
  const rootReal = fs.realpathSync(projectRoot);
  const absPath = path.resolve(rootReal, relativePath);
  
  // 4. 检查是否为 regular file
  const lstat = fs.lstatSync(absPath);
  if (!lstat.isFile()) {
    throw new Error(`${SecurityError.NOT_REGULAR_FILE}: Not a regular file: ${relativePath}`);
  }
  
  // 5. 检查符号链接逃逸
  const fileReal = fs.realpathSync(absPath);
  const relToRoot = path.relative(rootReal, fileReal);
  if (relToRoot.startsWith("..") || path.isAbsolute(relToRoot)) {
    throw new Error(`${SecurityError.SYMLINK_ESCAPE}: Symlink points outside project: ${relativePath}`);
  }
  
  // 6. 检查文件大小
  if (lstat.size > maxFileBytes) {
    throw new Error(`${SecurityError.FILE_TOO_LARGE}: ${relativePath} (${lstat.size} > ${maxFileBytes})`);
  }
  
  // 7. 读取为 Buffer 并用严格 UTF-8 解码（非法字节抛出 NOT_UTF8）
  const buffer = fs.readFileSync(absPath);
  try {
    const content = new TextDecoder("utf-8", { fatal: true }).decode(buffer);
    return { content, bytes: buffer.length };
  } catch (decodeErr) {
    throw new Error(`${SecurityError.NOT_UTF8}: Invalid UTF-8 in ${relativePath}`);
  }
```

### 6.6 Pi Agent 集成（使用 DefaultResourceLoader - 官方同型写法）

**重要变更**：不使用 `initialState.systemPrompt`，改用 `DefaultResourceLoader` 构造时传 callback 并显式 `await loader.reload()`。

```typescript
// packages/ui/src/lib/pi/agent.ts

import { DefaultResourceLoader } from "@mariozechner/pi-coding-agent";

interface InstructionsResult {
  content: string;
  loadedFiles: string[];
  skippedFiles: string[];
  totalBytes: number;
}

async function createPiAgent(projectPath: string, projectConfig: ProjectConfig) {
  // 1. 读取指令配置并构建内容
  const instructions = projectConfig.instructions;
  const result: InstructionsResult = instructions?.enabled 
    ? await buildInstructionsContent(projectPath, instructions)
    : { content: "", loadedFiles: [], skippedFiles: [], totalBytes: 0 };
  
  // 2. 创建 DefaultResourceLoader（构造时传 callback）
  const resourceLoader = new DefaultResourceLoader({
    cwd: projectPath,
    appendSystemPromptOverride: result.content 
      ? (basePrompts: string[]) => [...basePrompts, result.content]
      : undefined,
  });
  
  // 3. 必须显式 reload 后再创建 session
  await resourceLoader.reload();
  
  // 4. 创建 Agent
  const { session } = await createAgentSession({
    cwd: projectPath,
    resourceLoader,
    model,
    // ... 其他配置
  });
  
  return session;
}

// 构建指令内容（修正版）
async function buildInstructionsContent(
  projectPath: string, 
  instructions: InstructionsConfig
): Promise<InstructionsResult> {
  const contents: string[] = [];
  const loadedFiles: string[] = [];
  const skippedFiles: string[] = [];
  let totalBytes = 0;
  const maxTotalBytes = instructions.maxTotalBytes || 32768;
  
  for (const file of instructions.files || []) {
    try {
      // 安全读取文件
      const { content, bytes } = validateAndReadFile(
        projectPath, 
        file, 
        instructions.maxFileBytes || 8192
      );
      
      // 检查总大小限制（硬失败）
      if (totalBytes + bytes > maxTotalBytes) {
        throw new Error(`${SecurityError.TOTAL_TOO_LARGE}: Adding ${file} would exceed total limit (${totalBytes} + ${bytes} > ${maxTotalBytes})`);
      }
      
      totalBytes += bytes;
      loadedFiles.push(file);
      contents.push(`<!-- From: ${file} -->\n\n${content}`);
      
    } catch (err) {
      const errorMessage = err instanceof Error ? err.message : String(err);
      
      // 安全类错误和总大小超限一律硬失败
      if (errorMessage.includes("PATH_TRAVERSAL") ||
          errorMessage.includes("SYMLINK_ESCAPE") ||
          errorMessage.includes("NOT_REGULAR_FILE") ||
          errorMessage.includes("INVALID_EXTENSION") ||
          errorMessage.includes("FILE_TOO_LARGE") ||
          errorMessage.includes("TOTAL_TOO_LARGE") ||
          errorMessage.includes("NOT_UTF8")) {
        throw err; // 硬失败
      }
      
      // ENOENT（文件不存在）按 onMissingFile 处理
      if (errorMessage.includes("ENOENT")) {
        if (instructions.onMissingFile === "error") {
          throw err;
        }
        if (instructions.onMissingFile === "warn") {
          console.warn(`[Instructions] File not found: ${file}`);
        }
        skippedFiles.push(file);
        continue;
      }
      
      // 其他未知错误一律硬失败（不降级）
      throw err;
    }
  }
  
  return {
    content: contents.join("\n\n---\n\n"),
    loadedFiles,
    skippedFiles,
    totalBytes,
  };
}
```

## 12. ChatGPT 审查意见摘要

### 第一轮审查结论（原方案）
**需要修改**，方向可行但原方案在 Pi SDK 接法和安全边界上未收口。

主要问题：
1. 不应直接设置 `initialState.systemPrompt`，应使用 `DefaultResourceLoader`
2. 与 Pi 原生 AGENTS.md 发现机制可能重复注入
3. 安全边界不够严（需防范 `../`、symlink 等）
4. glob 设计太宽，首期应收敛
5. 变量替换职责混乱，应在项目创建时完成
6. 调试 API 可能泄露敏感信息

### 第二轮审查结论（修订版）
**有条件通过**，方向正确且已收敛，但实现契约与 SDK 真实 API 仍有偏差，需修正以下 3 点：

1. **SDK 示例代码需修正为官方同型写法**：构造时传 callback + 显式 `await loader.reload()`
2. **安全错误需与 ENOENT 分开处理**：越界、symlink 逃逸等必须硬失败，不能用 `onMissingFile`
3. **`agentsFiles` 模式语义不清**：建议 MVP 只保留 `append`，移到 Post-MVP

### 本修订版（第二轮后）已修改
- ✅ 移除 `mode` 字段，MVP 只保留 `append` 模式
- ✅ 修正 `DefaultResourceLoader` 用法（callback + reload）
- ✅ 安全错误分类（SecurityError enum），与 `onMissingFile` 分离
- ✅ 路径校验改用 `realpath + path.relative`
- ✅ 收紧文件类型（只允许 `.md`、`.txt`、`.mdx`）
- ✅ M2 增加自动化契约测试
- ✅ 日志降敏（生产环境只打 hash/文件名/字节数）
- ✅ 添加版本策略（按 0.62.0 验证）
- ✅ `agentsFiles` 模式移到 Post-MVP

### 第三轮审查结论（第四轮修订后）
**有条件通过**，12项里前11项已解决，第12项还有2处残留：
